# Anatomy v2 release candidate

Twelve objects now share white drawing materials, thin outlines, five functional colour families and sixty causal chapters. The watch, pen and keyboard establish the geometry and explanation contract; the other nine carry it across optics, input, transmission, motion, sound, pneumatics and storage.

The final art-direction pass opens each object with a full-width hero view, keeps Learn on demand and separates the enlarged HDD track guides from platter surfaces. Gallery thumbnails contain the objects without baked controls. Focus/Return preserves inspection context, and small screens keep settings reachable without scrolling.

The source adds actual cavities, bores, seats and linkages: a slotted nine-leaf lens iris, separate gamepad contacts, bevelled key bitting, pierced planetary gears, engine pushrods/rockers, brush connections, anchored speaker leads, corrected valve springs and separate HDD parking shelves.

Build with Node 22+, `npm ci`, `npm run build`. Open index.html or any object HTML offline. All thirteen entries are also included in dist, with per-object titles/canonical URLs and a sitemap. Browser checks use the pinned Playwright dependency.

Model dimensions and simplified mechanisms are authored teaching parameters. This release does not claim manufacturing tolerances, general force/contact physics, optical ray tracing, acoustic synthesis or educational efficacy.
